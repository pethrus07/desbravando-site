# Desbravando UTV website redesign

[Português](README.pt-BR.md) · English

Redesign of the Desbravando UTV website inside Wix. The client chose to stay on Wix, so this
repository does not hold the site itself. It holds what produces and feeds it: the design
generated by code, the content that goes into the Wix CMS through its API, Velo snippets, the
step-by-step assembly manuals and the QA scripts for the live site.

## Status

Active. Home page live on Wix since 2026-08-08; expedition pages being finished.

## The problem it solves

Each expedition needed many separate images to carry its information, and the event pages
had large empty areas on mobile. The redesign puts each destination on one page, fed by CMS
collections, with the Wix Events page used only for checkout.

## Stack

- Node.js scripts (ES modules), no framework
- pen.dev `.pen` files for the design, generated by `design/gerar.mjs`
- Wix REST API for the CMS (`design/wix*.mjs`), Wix Velo for page code (`velo/`)
- Playwright for previews and QA, loaded from the `qa-parresia` checkout on this machine

## Run locally

Requires Node 20 or newer.

```bash
npm run icones            # downloads the icon SVGs into design/.cache-icones
npm run design:gerar      # regenerates the .pen (has a lock, see design/README.md)
npm test                  # validates the .pen against the format vocabulary
npm run manual:servir     # serves the assembly manuals at http://localhost:8787
```

Scripts that talk to Wix need `.env.local` (copy `.env.example`). The `wix:*` scripts
**write to the live site**: run `npm run wix:testar` first.

## Tests

```bash
npm test
```

Checks the generated design file against the real `.pen` vocabulary. The `qa:*` scripts
check the live site in desktop and mobile browsers.

## Folder structure

| Path | What it is |
|---|---|
| `design/` | Design source, generators, Wix and QA scripts (see `design/README.md`) |
| `dados/` | Text of every module, per page, used by the manuals |
| `cms/` | CSV and JSON that go into the Wix CMS collections |
| `velo/` | Page code pasted into the Wix editor |
| `marca/` | Brand guide (text) and the scripts that vectorize the logo and build the favicon |
| `entrega/` | Notes on what was delivered (the rendered files stay out of git) |
| `docs/` | Plans, architecture, implementation notes, diagrams |
| `saida/` | Generated manuals (ignored by git) |

## Decisions and known limits

- The site stays on Wix by client decision. Payments and Wix Events are not touched.
- The `.pen` was born from code. Once someone edits it on the canvas, the canvas is the
  source of truth, and `gerar.mjs` refuses to overwrite it.
- Playwright is imported from an absolute path on the author's machine.
- The client's files (logo, photos, received documents, finished pieces) are not in git. The
  scripts that need them read from the folder in the `DESBRAVANDO_ARTES` environment variable,
  with `marca/` and `recebidos/` inside (see `design/lib/artes.mjs`). `npm test` does not need it.
